HIRUDOTERAPIA — STRONA STATYCZNA

Zawartość:
- index.html — treść strony
- styles.css — wygląd i układ strony
- script.js — menu mobilne i rok w stopce
- assets/gabinet-hirudoterapia.png — grafika nagłówkowa

PUBLIKACJA NA VERCEL PRZEZ CLI
1. Rozpakuj paczkę.
2. Zainstaluj Node.js, jeśli nie jest zainstalowany.
3. Otwórz terminal w rozpakowanym folderze strony.
4. Wykonaj:
   npx vercel
5. Przy pierwszym wdrożeniu zaloguj się i zaakceptuj domyślne ustawienia projektu.
6. Aby opublikować stronę produkcyjną, wykonaj:
   npx vercel --prod

Strona jest statyczna i nie wymaga frameworka ani procesu build.
